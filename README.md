# Kaliki
Its just a helper in Kali Linux whitch you can **edit easy.**
You can edit the Helper in the file, it is a usefully helper.
For now on its only for Linux.
Of course everything is **open source!**
# Get started
1. Go to Releases, download the last version and download the zip.
2. Extract the file:
<img width="1599" height="832" alt="image" src="https://github.com/user-attachments/assets/3f68f395-3c33-4fe2-a957-f0bddd90241d" />

3. Click on jarvis.py
4. Scroll down to this section:
<img width="1598" height="871" alt="image" src="https://github.com/user-attachments/assets/f25cf2a6-899c-44f4-ab1c-d9de97912f7d" />

5. Now you can edit the commands and so on.
6. Start the Helper with that command:
**cd ~/Jarvis && source venv/bin/activate && python3 jarvis.py**
<img width="1600" height="620" alt="image" src="https://github.com/user-attachments/assets/633c53ed-7c76-41b0-8cb2-18861e072809" />

7. Say "pc" and then the command you have edited in the jarvis.py!
